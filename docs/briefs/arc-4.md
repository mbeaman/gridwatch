## Seam decisions made in this brief (D54) — implement as written, escalate if they do not fit

1. **Edit-mode keys (§10, amended for the legacy keyboard encoding).** `e` enters and leaves edit mode. In edit mode: `H J K L` move the focused placement one unit; **`Ctrl-l` widens, `Ctrl-h` narrows, `Ctrl-j` grows down, `Ctrl-k` shrinks up** — the research's "Shift shrinks" cannot be encoded (VTE has no kitty protocol; `Ctrl-Shift-h` and `Ctrl-h` are the same byte), so the direction carries the sign; `s` cycles `manifest.footprints` (a placement of a kind that is not built cycles nothing); `S` followed by `h/j/k/l` swaps with the neighbour in that direction (`focus_dir` picks it); `a` opens the picker; `x` removes the focused placement; `u` undo and `Ctrl-r` redo over page snapshots; `w` saves; `Esc` leaves — with a one-line confirm in the key bar when dirty: `unsaved changes — w save · y discard · Esc stay`; `?` help lists these. Everything else (pages, `q`, `t`, `space`, `F12`) keeps working; component capture (`Enter`) is unavailable in edit mode. **Collisions:** an op that fails (`Overlap`, `OutOfBounds`) leaves the page unchanged, draws the attempted rect as a **red ghost** (`Role::Crit` border, no fill) until the next key, and says why in the key bar. The **dotted unit grid**: every unit boundary in the gutters is painted `·` in `Role::TextGhost`; the key bar shows `EDIT · <id> @ (x,y) w×h`.
2. **The picker.** A centred `overlay::panel` listing, in this order: configured instance ids not placed on this page, then every registered kind as `kind:<name>` (an anonymous default-options instance, §9); `j/k` or arrows move, `Enter` inserts at the kind's `default_footprint` by `insert_first_fit`, `Esc` closes; `NoRoom` toasts. Typing narrows the list by substring (no fuzzy crate).
3. **Mouse (§6).** In edit mode `Down` on a tile focuses and starts a drag; `Drag` moves by the unit delta between the press unit and the current unit (`unit_at`, the inverse of `tracks`, added to `gridwatch-ui::layout`), applied on `Up` (one undo step), previewed as a ghost while dragging — green (`Role::Ok`) when it fits, red when not; a press on the tile's **bottom-right corner cell** resizes instead of moving. `unit_at(spec, body, mode, x, y) -> Option<(u8, u8)>` is pure and proptested against `solve`: every cell of every solved tile maps back to a unit inside that placement.
4. **Undo/redo.** `undo: Vec<Page>` and `redo: Vec<Page>` of the current page, capped at 64; every successful op pushes; a page change or leaving edit mode clears both; `dirty` = the page differs from the last saved (or loaded) page.
5. **Save (§9).** `w` writes **`layout.toml` only**, through `toml_edit::DocumentMut`: the current file text (or the embedded default when no file exists — the config dir is created) is parsed, and for each page in memory the matching `[[pages]]` table's `place` array is **replaced** by inline tables `{ id = "cpu", at = [0, 0], size = [6, 3], view = "...", priority = N }` (`kind = "clock"` for anonymous ones; `view`/`priority` only when set/non-zero); every other key, comment and blank line survives — comments *inside* a `place` array do not (documented in `ARCHITECTURE.md` §9 and the CHANGELOG). Write is atomic (temp file in the same dir + rename), then the written text is re-parsed with `config::load_texts` against the current `config.toml` text and its pages compared to memory — a mismatch is an error toast and the temp file is removed. The content hash of the written bytes goes to the watcher (`WatchHandle::ignore_next(Layout, hash)` — the slot D53 left unused; the shell reaches it through a `Sender<(ReloadKind, u64)>` like the theme-file sender, no lock). Success toasts `layout.toml saved (N pages)`. `config.toml` is never written.
6. **`[effects]` (§7, theme data in `gridwatch-ui`, painter in `gridwatch-app::effects`).** The theme loader parses `[effects]` into `EffectHooks { startup, theme_swap, focus, alert }`, each `Option<EffectSpec { kind: String, duration_ms: u32, motion: Option<String>, lightness: Option<f32>, period_ms: Option<u32>, target: Option<String> }>`; unknown kinds warn at load and are ignored. The app maps kinds to tachyonfx 0.25.1 (`std`, `dsl` off — no DSL this arc): `sweep_in` (startup; `fx::sweep_in(Motion, 12, 0, Bg, (duration, QuadOut))` over the body), `fade_in` (startup, `fx::fade_from(Bg, Bg, …)`), `dissolve`/`fade` (theme_swap: `fx::fade_from(old_fg, old_bg, 150–600)` over the body), `fade` (focus: `fx::fade_from_fg(Role::BorderFocused, 200)` over the newly focused tile's outer rect), `hsl_pulse` (alert: `fx::repeating(fx::ping_pong(fx::hsl_shift(Some([0,0,lightness]), None, period/2)))` over the **banner row** only — the banner already pulses without it; with the effect on, the pulse is the tachyonfx one and the heartbeat reverse is off). Effects are `!Send` and live in the shell; they run in `draw_frame` after tiles, chrome and overlays and before the HUD; the frame loop treats `effects_running()` as an animation cause at `fps`; event effects are bounded to 600 ms (`with_duration`), area-scoped, and **never veil** the focused tile, an alerting tile, the banner or the key bar (D28's rule holds for effects too: the focus fade is on the focused tile itself and is the one exception). **Budget:** `[effects] budget_ms` (config, default 4): the painter times itself per frame; a 2 s moving average above budget disables event effects for the run, logs once and toasts once. `--no-effects` (CLI) and `[effects] enabled = false` (config) short-circuit everything; `shot` and tests run with effects off (determinism), except the effects tests, which drive the painter on a `Buffer` with a fixed tick.
7. **`[flourish]` (§7).** Parsed into `Flourish { grid_floor: bool, sun: bool, big_clock: Option<PixelStyle>, marquee: bool }`. `grid_floor` and `sun` draw in the **empty units** of the page (units no placement covers, computed from the tracks) as string art cached per rect: the floor is perspective lines in `Role::TextGhost`, the sun is stacked `▀`/`█` rows through the `Title` gradient — both are drawn by the shell after tiles, never over one, and are off in every theme but `retrowave` (already true in its file). `big_clock` maps to the clock component's existing big-number tier through `theme.widgets.big_number` (no new component code: the theme's `[widgets] big_number` already selects the pixel style; `flourish.big_clock.pixel` overrides it for the clock kind — implement as a per-kind override of `widgets`, the same mechanism as D52's gradient overrides). `marquee` is arc 6's.
8. **`phosphor-amber`.** `inherits = "phosphor-green"` (flattened by D52's amendment) with an amber palette (`#ffb000` on `#100c00`), roles as luminance steps, passes the gate on its own numbers; a swatch snapshot; a THEMES.md row.
9. **`contrast.autofix` (§7).** A theme's `[contrast] autofix = true` lets the loader move `text`/`text_muted` toward the floor: lighten (dark variant) or darken (light variant) the foreground in Oklab `L` steps of 0.02 until the WCAG pair passes or 20 steps are spent; each fix is a warning (`WCAG autofix: text_muted #2e8b3a → #3aa650 (3.0:1 on panel)`), so the author sees what changed. Off by default; no shipped theme turns it on.
10. **`matrix` (D28, D31, D34) — the seams.** `class = "showcase"`; `[ambient]` parsed into `AmbientSpec { kind: "matrix_rain", fps: u8 (24), density: f32 (0.20), speed: f32 (1.0), reveal: Vec<String>, reveal_ms: u32 (2500), governor: bool, light: Light { fade_s: f32 (12), trail_ms: u32 (900), sweep_s: f32 (20), head: Color, floor: Color (black), relight_on_update: bool } }`; a `Rain` gradient (a ninth gradient id, optional in the file — absent means the theme has no rain palette and the layer refuses to start with a warning); `[glyphs] rain = "katakana" | "ascii"` (half-width katakana U+FF66–U+FF9D plus digits and `:・"=*+<>¦|` — all East Asian Width `H`; the ascii set is `0-9A-Z:.=*+<>|`). The **ambient layer** is `gridwatch-app::ambient`: a post-render pass in `draw_frame` that takes the finished frame as the *mold*, keeps `lit_at: Vec<u32>` (frame index per cell) and a fixed droplet pool sized `density × columns`, and writes the screen from scratch every ambient frame per D34: a droplet head prints a rain glyph at `head`; the cell under a head that had content in the mold shows that content at `lit = 1` from the next frame; content cells fade from their own colour to `floor` over `fade_s` quantised to the `Rain` LUT's 64 steps; empty cells under a trail fade at `trail_ms`; every content cell of the page is re-lit at least once per `sweep_s` by a dense fall; `relight_on_update` compares the mold to the previous mold and re-lits changed cells; pinned cells (the focused tile, any tile whose sources have an active Warn/Crit alert, the banner row, toasts, the key bar, the tile under the mouse, and everything for `reveal_ms` after a key) are copied from the mold at `lit = 1`; `V` re-lights the whole page; `L` toggles the lock (everything lit, rain in gutters only). The layer runs at `fps` while the terminal is focused and not paused, is **frozen** (no frames, the last screen stays) on `FocusLost` and `space`, and never invalidates the render cache. **Determinism:** the RNG is seeded from `hash(theme name) ^ frame index`, and the frame index advances on the virtual clock in tests, so two runs from the same seed produce identical buffers. **Governor:** measured p95 frame time > 16 ms or bytes/s > S2 over a 2 s window steps `fps 24 → 16 → 12 → 8`, then `density × 0.75`, then `sweep_s × 1.5`, then gutters-only; recovers one step per 30 s; the HUD shows the step. State ≈ 4 B × cells + the pool.
11. **Keys added:** `V` (re-light), `L` (lock lit) — already reserved in §10 and stubbed as toasts since arc 3; edit mode's keys from seam 1. `Command::SaveLayout` (exists, unrouted) is routed to the save path; `Command::Run` stays arc 8.

## Gotchas already verified — do not rediscover
`tachyonfx::Duration` is a custom `{ milliseconds: u32 }` unless the `std-duration` feature is on — convert with `Duration::from_millis(elapsed.as_millis() as u32)`; `EffectRenderer<Effect>` is implemented for `Buffer` (`render_effect.rs:18`), so the painter runs on the frame buffer, not a `Frame`. `Effect` is `!Send`: it lives in the shell, and `Shell` therefore stops being `Send` — nothing sends it across threads today (the determinism test builds one on the test thread; check `crates/app/tests` before assuming). `hsl_shift(None, None, …)` panics — always pass the fg triple. Crossterm's legacy encoding sends `Ctrl-h` as backspace (`0x08`) — match `KeyCode::Backspace` with `mods.ctrl` *or* `KeyCode::Char('h')` with ctrl, and test both; `Ctrl-j` arrives as `Enter`/`0x0a` on some terminals — accept `KeyCode::Enter` with ctrl for it. `toml_edit`'s `ArrayOfTables` keeps its tables' decor; replacing `place` with a fresh `Array` of `InlineTable`s keeps the array's own trailing comment but drops comments between items — that is the documented loss. Half-width katakana: East Asian Width `H`, one cell in VTE; `unicode-width` agrees (the workspace already depends on it); DejaVu Sans Mono lacks them and fontconfig falls back to Noto Sans Mono CJK JP on torch — the glyph check row is Matt's. The `layout-cache` feature of ratatui is on; `Buffer::merge` exists on `ratatui-core` 0.1.2. `Shell::new` does not change in this arc; the watcher's hash sender is a new `Option<Sender<…>>` field set by `run_terminal`, like `watch_theme_files`.
