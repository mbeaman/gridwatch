## Gotchas
CPU% is Irix-mode (can exceed 100 per process later; per-core bars are 0–100). First tick has no delta — render `—`, never 0. `guest` subtraction order matters. `cores` must fit 56 wide (3-cell bars ×16 + labels). Gradient bars: one LUT lookup per cell, styles shared per run (P6 depends on it). Never `Instant::now()` — `cx.now`.

## Escalate to Fable (do not improvise)
Any store/ui/app signature that doesn't fit; layout solver behaviour that looks wrong at odd sizes; P1/P5/P6 red after one honest fix attempt; anything touching the panic hook, channels or the render cache.
