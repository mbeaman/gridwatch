## Gotchas already verified — do not rediscover
`/dev/i2c-*` are `root:i2c 0660` and the user is in `i2c` — no sudo; **an agent never opens `/dev/i2c-*` itself** (MACHINE.md): the live pins test is run by hand, and the review's user-path lens must be told so. `detect_bus` probes bytewise and needs `Reading::plausible()` (max volts in 5–20 V): a deeply idle GPU answers zeros → `NoTelemetry` at start and implausible readings later — that is `TelemetryLost`, not an error. The root logger (PID 6755, bytewise, 0.5 s) is a concurrent reader: the kernel's per-adapter lock makes every SMBus transaction atomic, so contention costs latency and the odd EIO, never a corrupted reading (digest §2) — expect a `TelemetryLost` flicker and let the lifecycle absorb it. `Reading::balance()` is `None` below 0.05 A on the lowest pin; the exporter prints `+Inf` for it — parse `+Inf`/`-Inf`/`NaN`. `astral_watch::config::Config` is `deny_unknown_fields`: never write gridwatch keys into the user's astral-watch file. `Lifecycle::observe` wants `Instant` — fine in a source, forbidden in a component; the synth scripts its events instead. The exporter is **not** running on torch and no astral-watch config exists (MACHINE.md) — auto mode lands on i2c here; test the exporter path against a captured text and a tiny in-test TCP listener. `SourceCtx::sleep_until` re-parks on a non-Stop control (BACKLOG): a `SetOption("interval_ms")` takes effect on the next tick, not instantly — acceptable; do not "fix" the seam.
