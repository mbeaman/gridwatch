## Build order

1. **Scaffold** — `cargo new` the six crates per `WORKSPACE.md` tree; `[workspace.dependencies]` exactly as pinned there (ratatui-core/-widgets features explicit — core default is `[]`); `rust-toolchain.toml`, `clippy.toml` (`disallowed-methods`: `ratatui::init`, `ratatui::try_init`, `ratatui::run`, `ratatui::restore`), `deny.toml` (allow ISC + CDLA-Permissive-2.0; ban cpal, mpris, pipewire, libpulse*, ansi_colours, enum-map, sysinfo), `.github/workflows/ci.yml` per §14, the `Makefile` shortcut targets and `.cargo/config.toml.example` (the git-ignored astral-watch `[patch]` template) per the WORKSPACE tree. CI green on the empty scaffold before anything else. One-time tooling on torch: `cargo install cargo-deny cargo-audit cargo-insta`.
2. **`gridwatch-store`** (§4.1–§4.5, headless, target ~1 s build): `Ts`/`Clock` (Real|Virtual); `MetricId`/`Label`/`Key<T>`/`Datum`/`RecordValue` blanket impl + `KeyMeta`/`CATALOGUE`/`lookup()`; `Ring` (VecDeque — **no unsafe anywhere**); series + `Retention {2400, 10 min}`; `Store::apply` + read API + `resample` (caller buffer); `Msg`/`Batch`/`ControlMsg`/`Reload`; **three channels** (data bounded 4096 `try_send`, control unbounded drained first, input unbounded drained before both); `InputEvent` serde mirror (no crossterm in this crate — CI per-crate check enforces); `Source`/`AsyncSource`/`Sampler`/`SourceCtx` with **`sleep_until` zero-poll** (parks on ctl `recv_timeout`, deadlines on the `[perf] phase_ms` grid — §4.3, P5); `Demand{Level, Detail}`; `SourceStatus`; `demo::Synth` seeded xorshift for `sys` + `cpu` keys; `keys/{sys,cpu}.rs` incl. `sys.pid_digits`, `sensor.temp_c{k10temp:*}`.
3. **`gridwatch-ui`** (§4.6, §6, §7): `View`/`Span`/`Paint`/`Renderer` (all eleven nodes incl. `Segmented` — D37); `Component` trait (`view`, `tiers` — cumulative, `zoom_only` suffix — `demand`, `tick`, `title`, keys); `Manifest`/`ComponentDef`/`Registry`/`Chrome`/`Capability`; layout: `tracks` (exact sum, ≤1 variance — oracle-test against `Layout::horizontal(vec![Fill(1); n]).spacing(Spacing::Overlap(1))`), `thresholds` (131×37 / 109×27 for the default spec), `solve` (Configured/Dense/Stack, 2-cell hysteresis, chip fallback), `hit`/`unit_at`/`focus_dir`, pure edit ops (proptests: never overlap, never out of bounds — the ops land now, the edit *mode* is arc 4); theme loader v1 (roles array — **no enum-map**, `$palette`, Oklab 64-entry gradient LUTs via `palette`, glyph tiers, border sets incl. rounded→`BorderMode::Each`, title styles, `class = "quiet"|"showcase"` parsed (default quiet, behaviourally inert until arc 4), ColorMode ladder: CLI > config > `NO_COLOR`→real `mono` theme > `COLORTERM` > `TERM`; in-tree nearest-256/16; a theme file is self-contained — `theme.schema.json` requires every role and all eight gradients); embedded `modern`/`mono` (retrowave = 1b); default `Renderer` parameterised by `[widgets]`; overlay (help, too-small, stats HUD scaffold); `dump::cells` (RLE styled) + `dump::ansi`; testkit (`snapshot_matrix!` = view-tree YAML + rendered buffer at `real_grid_sizes()` 250×70 + 120×40, `role_swatch!`, `assert_never_panics` (0×0→richest min + zoomed 248×66), `assert_min_tier_fits`, `assert_tiers_well_formed`).
4. **`gridwatch-sources`**: supervisor only (`spawn_source`: catch_unwind, backoff 250 ms→30 s, restart counter, phase-aligned deadlines) + registry plumbing. No real source in 1a.
5. **`gridwatch-components`**: `clock` (the template — Chrome::Borderless, tui-big-text via `BigNumber` node) and `sources` (status table from the store).
6. **`gridwatch-app`** (§5, §10, §11): terminal.rs — **never `ratatui::init`**: `enable_raw_mode` → `execute!(EnterAlternateScreen, EnableMouseCapture, EnableFocusChange)` → `Terminal::new(CrosstermBackend)`; mirror on exit; PanicPolicy hook (thread-local; contained for source threads + per-component calls, restore-and-eyre otherwise); stderr `dup2` to `$XDG_STATE_HOME/gridwatch/gridwatch.log` **before** the alt screen; input thread (sole `event::read` caller, crossterm→`InputEvent` conversion, focus events; **start-focused default** — absent focus reporting ⇒ assume focused, only a real `FocusLost` throttles); loop.rs — drain input→control→data(≤3 ms) → cached solve → Demand write (levels + `demand(tier)` detail max) → tick → **render cache** (key: source generations + tier + rect + theme id + zoomed + focused + anim frame + view hash; blit via `Buffer::merge`) → dirty-gated draw with coalescing; `Role::Bg` painted first; pages/hotkeys, Tab/hjkl focus, Enter/Esc capture, `z` zoom, `d` dense, `t`/`T` theme, `space` pause, `V`/`L` no-ops until arc 4b, `F12` HUD (frame p50/p95, changed cells, bytes, mode, cause histogram), `S` screenshot; config loading (two files, spans via `toml::de::Error::span()`, layering defaults←file←`GRIDWATCH_*`←CLI, options-disjointness test); FocusLost → Hidden + Meters (P4/P21); `run<B: Backend>` generic.
7. **`gridwatch` bin**: clap `run [--demo [--seed]|--page|--theme|--fps|--color|--no-mouse|--stats|--stats-log F]`, `shot --format ansi`, `config check|default`; `builtin_registry()`.
8. **Schemas**: `schema/{config,layout,theme,view}.schema.json` + a CI job validating the shipped defaults and fixtures against them (D33); `config.schema.json` requires `schema = 1` (the version marker `config migrate` will key on, D39).
9. **`scripts/perf/measure.sh`** per `PERFORMANCE.md` protocol (per-thread pidstat, task-summed voluntary switches, Δwchar, pmon, pw-top; paused baseline; appends the dated row).
