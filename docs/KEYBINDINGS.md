# Keys

> **Generated by `gridwatch keybindings` (D33/D59) — do not edit.** CI regenerates this file and fails on drift. The global table is `gridwatch-ui::keys::GLOBAL`, which also draws the key bar and the `?` overlay; a component's keys are its `Manifest.keys`, so a component that adds a key documents it by declaring it.

## everywhere

| key | does |
|---|---|
| `^q` | quit from anywhere |
| `?` | this help |
| `1-9` | go to a page by number |
| `[ ]` | previous / next page |
| `t` | cycle through the built-in themes |
| `T` | reload the current theme from its file |
| `space` | pause the sources (pins keeps sampling) |
| `F12` | the stats HUD (frame time, cells, bytes) |

## the grid

| key | does |
|---|---|
| `q` | quit (when no component holds the keys) |
| `hjkl` | move focus (arrows work too) |
| `Tab` | focus in reading order (Shift-Tab back) |
| `Enter` | give the keys to the focused tile (Esc takes them back) |
| `z` | zoom the focused tile |
| `d` | dense mode (override the size-derived one) |
| `r` | start / stop recording a journal |
| `a` | acknowledge the alert banner |
| `A` | the alerts overlay: what is active, and the log |
| `S` | write a screenshot into the state directory |
| `e` | enter edit mode |

## edit mode

| key | does |
|---|---|
| `HJKL` | move the focused tile by one unit |
| `^h ^l ^j ^k` | narrow · widen · grow down · shrink up |
| `s` | cycle the tile's footprint |
| `S then hjkl` | swap with the neighbour (Esc cancels) |
| `a` | add a tile from the picker |
| `x` | remove the focused tile (Delete too) |
| `u  ^r` | undo · redo |
| `w` | save layout.toml |
| `Esc` | leave edit mode (asks if there are unsaved edits) |

## showcase themes

## Component keys

A tile's keys are live only while it holds the keys — focus it and press `Enter`; `Esc` gives them back. A component with no row here takes no keys of its own.
