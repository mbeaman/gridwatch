### Added

### Fixed
- Two startup defects Matt hit on first use: running gridwatch where stdout is not a tty exited **silently** — crossterm's "No such device or address" went to the log file because stderr was redirected before the terminal was even opened — and a terminal too small to draw showed a **blank screen**, because §6's too-small notice existed in `gridwatch-ui` and nothing ever called it. The tty check now happens first and reports on the real stderr, the stderr redirect waits until the terminal is up, and an undersized terminal says `158×1 — gridwatch needs at least 20×3`.
- Arc 1b review (4 lenses, 20 agents, 34 findings): the `big-number` tier no longer hands the `—` sentinel to a font that has no glyph for it (it fell back to a silently blank tile); the per-core id labels moved off `TextGhost`, which was 1.3:1 against the panel; the `cores` block says "waiting for the first delta" instead of painting 32 zero-height bars; the task line says `pids`/`tasks` rather than borrowing htop's `procs`/`thr` for different quantities; the frame loop draws its first frame before parking on input (251 ms → 1 ms); both cpu sources prime their first sample instead of waiting for a cadence boundary (3.0 s → 252 ms); `gridwatch-components` no longer dev-depends on `gridwatch-sources` (crate direction); a placement naming an unknown tier now toasts as well as logs.
