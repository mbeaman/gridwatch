# Changelog

All notable changes to gridwatch. One minor version per arc (see `docs/ROADMAP.md`).

## [Unreleased]
### Added
- Arc 1b — the grid lights up: the **cpu source** (procfs 0.18, htop 3.4.1's formulas verbatim — guest subtracted from user/nice, `systemall`, `virt = steal+guest`, saturating deltas, `cached = Cached + SReclaimable − Shmem`, `usedSwap` minus `SwapCached`), PSI, load, uptime, task counts, `pid_max` digits, per-core `scaling_cur_freq`, the sysfs die/core map and k10temp read **by label** (torch has no `temp2`); the **htop component** with four cumulative tiers — `tiny` (8×3) → `big-number` (12×4) → `meters` (30×6) → `cores` (56×12) — drawing htop's four-segment CPU meter, its memory and swap meters, tasks/load/uptime, the pressure row and 32 gradient core bars grouped into real CCD blocks with per-block MHz and `Tccd`; htop's grid view options parse and validate today; `retrowave` verified end to end; `fixtures/procfs/` (two recorded ticks) and `fixtures/layouts/laptop-120x40.toml`; view-tree and styled-cell snapshots at every real grid size; the first live performance rows.
- Arc 1a — the core seam: six-crate workspace (`store ← ui ← components ← app ← bin`, `store ← sources ← app`); typed single-writer `Store` with three channels and drain order input→control→data≤3ms; `View` tree + `Component`/`Renderer`/`Theme` contracts with Oklab gradient LUTs and the ColorMode ladder; 12×6 grid solver with configured/dense/stack modes and 2-cell hysteresis; source supervisor (catch_unwind, backoff, `Demand` zero-poll timers); app shell (render cache, heartbeat, panic containment, focus/zoom/pause/theme keys, F12 HUD); `gridwatch run [--demo]`, `shot` (byte-deterministic, D41), `config check|default`, `doctor`; themes retrowave/modern/mono; clock + sources tiles; schemas + snapshot testkit + perf measure script. First measured P-rows: idle demo 0.0% CPU, 4 wake/s, ~0 KB/s, 10 MB RSS.
### Fixed
- Two startup defects Matt hit on first use: running gridwatch where stdout is not a tty exited **silently** — crossterm's "No such device or address" went to the log file because stderr was redirected before the terminal was even opened — and a terminal too small to draw showed a **blank screen**, because §6's too-small notice existed in `gridwatch-ui` and nothing ever called it. The tty check now happens first and reports on the real stderr, the stderr redirect waits until the terminal is up, and an undersized terminal says `158×1 — gridwatch needs at least 20×3`.
- Arc 1b review (4 lenses, 20 agents, 34 findings): the `big-number` tier no longer hands the `—` sentinel to a font that has no glyph for it (it fell back to a silently blank tile); the per-core id labels moved off `TextGhost`, which was 1.3:1 against the panel; the `cores` block says "waiting for the first delta" instead of painting 32 zero-height bars; the task line says `pids`/`tasks` rather than borrowing htop's `procs`/`thr` for different quantities; the frame loop draws its first frame before parking on input (251 ms → 1 ms); both cpu sources prime their first sample instead of waiting for a cadence boundary (3.0 s → 252 ms); `gridwatch-components` no longer dev-depends on `gridwatch-sources` (crate direction); a placement naming an unknown tier now toasts as well as logs.

### Changed
- `swap.used_b` now carries htop's `usedSwap` (`SwapTotal − SwapFree − SwapCached`); `cpu.topology` and `swap.cached_b` join the catalogue (D43). `--stats-log` samples on its own 1 Hz clock and its line gained `bytes`, `first_frame_ms` and `sources_live_ms` (the last two also in the F12 HUD) so P6's and P18's rows can be evidenced from one run (D44); `feed_synth` marks the demo source `Ok` so headless shots stop showing it as `starting`.
